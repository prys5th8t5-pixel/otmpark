# OTMPark – nettside

Den publiserte siden er `index.html` (passordbeskyttet). Personvernerklæringen ligger åpent i `personvern.html`.

`/app/` er forhåndsvisning av app-prototypen.

Endringer gjøres i `kilde/src.html`. Den låste `index.html` bygges på nytt av OTMPark sin assistent etter redigering.
